# Publications

Each subdirectory is one immutable, citable release snapshot.

```text
publications/<release>/
```

Use adjacent release directories for adjacent products. Do not split one
publication across top-level artifact-family directories.

A manifest must distinguish a standalone publication from a version in an
evolving series. Later releases of the same series use Zenodo's **New version**
workflow in one record lineage. Each snapshot has its own Version DOI; the
Concept DOI remains stable across the series.
